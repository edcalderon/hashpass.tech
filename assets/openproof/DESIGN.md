# OpenProof visual system

- **Mood:** credible, calm, premium and technical; no speculative crypto imagery.
- **Canvas:** obsidian `#050812`; surfaces `#0B1220`; primary text `#F7F9FF`; secondary `#AEB9CB`.
- **Semantics:** HashPass violet `#8B7CFF` for claims, electric cyan `#4DD8FF` for public/query paths, mint `#68E0AD` for ownership/verified state, amber `#F4BD68` for temporary or expiring evidence.
- **Type:** HashPass web fonts Fraunces, Manrope and IBM Plex Mono; video uses high-contrast system sans and mono fallbacks.
- **Motion:** deterministic eased entrances, restrained depth, no loops. Content remains legible without animation and reduced-motion removes nonessential movement.
