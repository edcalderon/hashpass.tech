# @hashpass/support-widget

Framework-agnostic Web Component for the HashPass Support launcher.

```html
<script src="https://cdn.hashpass.tech/support-widget/v1/index.js" data-hashpass-app-id="PUBLIC_APP_ID" defer></script>
<hashpass-support app-id="PUBLIC_APP_ID" locale="es" position="bottom-right"></hashpass-support>
```

The component uses Shadow DOM, plain-text rendering, English/Spanish labels, keyboard-focusable controls, and `@hashpass-tech/sdk` for all ticket operations.
