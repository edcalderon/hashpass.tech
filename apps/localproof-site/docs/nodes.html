Local Nodes

Local Nodes distribute useful destination information over nearby Wi‑Fi when mobile data is weak, unavailable, or too expensive. They are distribution infrastructure, not miniature cloud servers.

Node responsibilities

  • Create a local Wi‑Fi access point.
  • Serve a lightweight captive portal.
  • Distribute a compact destination pack.
  • Expose essential information during zero-connectivity periods.
  • Report device health and content freshness when upstream connectivity returns.

Recommended deployment locations

Tourism offices, hotels, hostels, cafés, attractions, transport terminals, trailheads, rural community venues, and temporary events.

Deployment flow

Provision device
  ↓
assign destination + venue
  ↓
load destination pack
  ↓
install + power
  ↓
verify local portal
  ↓
place QR / signage
  ↓
monitor health + freshness

Hardware design principle

The visible product can feel premium and local—wood veneer, warm materials, destination artwork—while the electronics and structural carrier remain standardized for scalable manufacturing.

Offline limitations

A captive portal on a local HTTP origin should not be presented as if it can securely install a full HTTPS PWA. LocalProof should be explicit about what works locally and what requires prior installation or secure connectivity.
