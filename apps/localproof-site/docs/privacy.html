LOCAL-FIRST DATA

Privacy Principles

LocalProof should use offline capability to reduce unnecessary data collection rather than treating every traveler interaction as an analytics event.

Default principles

  • Local-first: perform search and destination retrieval on-device when practical.
  • Minimum telemetry: collect only what reliability, security, aggregate measurement, and explicit rewards programs require.
  • No account required: travelers should be able to access core QR destination information without creating an identity.
  • Separate datasets: guide verification records are not the same as anonymous traveler usage.
  • Explain rewards: operators should understand which metrics affect tiers or reputation.
