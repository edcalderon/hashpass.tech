# Demo script

1. Open LocalPass and frame the problem: cloud AI disappears when the signal does.
2. Show the compact Guatapé pack and choose **Download for offline use**.
3. Ask: “I have 3 hours, COP 100,000. I like nature and local food.”
4. Highlight the time/budget fit, no-internet markers, and local-operator emphasis.
5. Enable **Simulate offline** and refresh the page.
6. Ask: “I have 2 hours and COP 50,000.” The local engine returns a new plan.
7. Open **Local businesses**, then **Essential**, without restoring connectivity.
8. Close: “LocalPass brings useful AI to the devices and connectivity people actually have.”

Before recording, test Chrome desktop and a narrow mobile viewport. In DevTools, set Network to Offline only after the pack and service worker finish installing; refresh and repeat steps 6–7.
