# Support integration examples

These snippets show the supported integration shapes for the HashPass support clients. They are examples, not standalone applications. Replace `PUBLIC_APP_ID` with the app ID configured for your integration.

- [Vanilla web component](./vanilla.html)
- [React component](./react.md)
- [Next.js client component](./next-client.md)
- [Expo / React Native controller](./expo-react-native.md)

The vanilla example's source-relative TypeScript import is a repository-development reference, not a standalone deployable page. For deployment, use the CDN setup in the [widget package README](../../../packages/support-widget/README.md). See also the [React package README](../../../packages/support-react/README.md) and [native package README](../../../packages/support-react-native/README.md).
